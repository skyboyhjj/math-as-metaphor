# 一个定理如何被造出来：阿罗定理里的三次自由选择

> 上期说，曼宁转述阿罗时漏了两条公理——无限制域和非独裁。这一期回答：**为什么偏偏是这两条最要紧**。
> 答案不在公理本身，在三次选择。

---

## 一、先分清两个「三」

上期讲阿罗造定理用了三步：重构对象、选公理、证明得反直觉。

那是**动作**——他做了这三件事。

这一期讲另外一样东西：这三步里有三个地方，阿罗本可以不这么走，但他这么走了。

那是**自由**。

- 三步回答「他做了什么」
- 三次选择回答「他为什么可以不这么做」

区别在哪？动作是流程，走完才知道结果；选择是岔路口，每一次都可以拐向别处。

而且这两组「三」不是一一对应的，这一点很要紧：

- 第二次选择（选公理清单）对应「自由选公理」那一步，是唯一被明确说出来的
- 第一次和第三次选择，都压在「重构对象」这一步里——那一步同时决定了「社会的意见长成什么样」和「哪种结果算不合格」

**一次动作里藏了两处选择，而只有第三处被说了出来**。这就是为什么曼宁数出了公理，却没数出另外两次。

**一个定理如果只有动作没有选择，那它就是发现。有了选择，它才是创造**。

---

## 二、第一次选择：把「哪种最好」换成「存不存在」

阿罗之前，人们问的是：

> 哪种投票方法最能反映民意？

这个问法藏着一个预设：**「投票方法」是一个现成的范畴**，任务是在里面挑最好的那个。

阿罗把问题整个换了：

> **存不存在**一个函数，把每个人的偏好排序变成社会的偏好排序，同时满足以下几条？

从「哪个最好」变成「有没有」。

这一步有多重要？看两种问法的难度差别：

| | 优化问法 | 存在问法 |
| :-- | :-- | :-- |
| 需要什么 | 一把尺子（怎么算「最好」） | 一组性质（什么算「合格」） |
| 争议在哪 | 尺子本身 | 性质本身 |
| 怎么答 | 比较所有候选 | 构造一个，或证明全部失败 |

**优化问法必须有尺子，而尺子本身就是争议**。你说「最能反映民意」，那「反映」怎么度量？多数票？接近度？满意度？每一种度量都能被攻击。

存在问法绕开了这把尺子。它不问「多好」，只问「有没有」。

而且存在问法有一个优化问法给不了的好处：**否定的回答是可证的**。

要说「没有最好的投票法」，你得把所有方法比一遍——做不完。
要说「不存在满足条件的函数」，你只要证明所有候选都失败——而这可以用一个固定的反例结构完成。

阿罗的证明就是这么走的：他不比较任何两个方法，只盯着「决定性集合」这一个结构，逼它一路收缩，最后收缩成一个人。

**这就是第一次选择的收益：把「比不完」换成「证得出」**。

顺带说一个边界。这个换法有个代价——定理只在「至少 3 个选项」时才成立。我们验过：

| 选项数 | 多数决是否满足全部公理 |
| :-- | :-- |
| 2 | 满足（8 个偏好剖面，帕累托违反 0 次） |
| 3 | 不满足（A 胜 B、B 胜 C、C 胜 A） |

两选项时社会排序只有两种可能，没有第三项可以循环，传递性白送。选项一到 3，循环就有了缝。

**「3」不是随手写的，它是定理失效的最小门槛**。

## 三、第二次选择：五条公理，每条单独看都无可争议

这是曼宁讲到了的那一次。阿罗选了五条：

| 公理 | 它说的话 | 反对它等于说什么 |
| :-- | :-- | :-- |
| 无限制域 | 任何偏好组合都允许 | 「有些人的偏好不算数」 |
| 帕累托 | 全体一致则社会也一致 | 「大家都同意也不算」 |
| IIA（无关选项独立性） | 只看各人对这两个选项的排序 | 「退赛的选手可以影响比赛」 |
| 非独裁 | 没有一个人决定全社会 | 「独裁可以接受」 |
| 集体理性 | 社会偏好必须是弱序（完备 + 传递） | 「投票结果不必是个排序」 |

**五条单独拿出来，没有一条能被痛快地否掉**。这是阿罗选得准的地方——他挑的是「软肋最少的五条」。

但仔细看，这五条不是一个层次的东西。前四条讲的是**输入怎么处理**，最后一条讲的是**输出必须长什么样**。

而最后一条，才是引擎。

道理很简单：如果社会的意见不必是一个排序，那你完全可以输出一个循环，然后说「这就是民意」。石头剪刀布在循环，但没人说它错。

**「社会偏好必须是弱序」这一条，把「投票结果」从「谁赢」升级成了「完整排序」**。升级之后，才谈得上「排序可能不存在」。

这一条最不像「公平」的要求，也最少被讨论——因为它是关于**结论的形状**，不是关于**程序的公正**。

上期说曼宁漏了两条。其实漏的不止两条：他连这一条也没提，而它恰恰是把前面几条拧成死结的那一根。

## 四、第三次选择：把独裁当失败标志

到这里是本期最反直觉的一段。

关于阿罗定理，通行的说法是：

> 阿罗证明了没有完美的投票制度。

精确的说法是：

> 阿罗证明了**只有独裁**。

这两句差别很大。

「没有完美的」暗示「接近完美的也许有」——读者会想，那我们找个 90 分的方案行不行。
「只有独裁」则说明：**凡是非独裁的规则，必然违反某条公理**。没有 90 分，也没有 60 分，只有 0 分和「有一个人说了算」。

那独裁是什么？常识告诉我们，独裁是坏东西，所以要排除它。

**但事实反过来**。

我们把所有可能的聚合规则摊开算了一遍。成对比较这个形式本身就包含了 IIA——社会的成对结论只看各人对这两个选项的排序。在这个前提下，再施加帕累托（全体一致则一致）和反称（社会不能同时说 A 胜 B 和 B 胜 A），剩下 8 个候选：

| 候选规则 | 能否给出社会排序（弱序） |
| :-- | :-- |
| 多数决 | 不能（三选项下产生循环） |
| 独裁者 1 | 能 |
| 独裁者 2 | 能 |
| 独裁者 3 | 能 |
| 其余 4 种加权规则 | 不能 |

216 个偏好剖面逐个检验，**通过传递性检验的只有 3 个，全是独裁型**。

所以「非独裁」这一条的真实身份是：

**它排除的不是坏东西，是唯一的好东西**。

那些「看起来更公平」的规则——多数决、加权多数、各种折中——全都过不了传递性。只有独裁能过。

**这就是不可能性定理的配方**，从来都是这三件套：

1. 一个**足够宽**的对象类（宽到包含一个平凡解）
2. 一组**足够强**的公理（强到排除所有非平凡解）
3. 结论：**只剩平凡解**

独裁就是这个平凡解。它不是因为「不民主」被排除，是因为它是唯一能活下来的那个。

**任何不可能性定理都必须有一个平凡解**。没有平凡解，定理就退化成「什么都不存在」——那是废话，不是定理。

## 五、三次选择的共同点：都是划界

把三次摆在一起看：

| 次数 | 划的什么界 | 从哪划到哪 |
| :-- | :-- | :-- |
| 第一次 | 问题的形状 | 从「所有投票方法」划到「满足函数形式的聚合规则」 |
| 第二次 | 合格的标准 | 从「所有聚合规则」划到「满足五条的」 |
| 第三次 | 失败的定义 | 从「满足五条的」划到「只剩独裁」 |

每一次都在**缩小可能世界**。三次划完，剩下的东西少得可怜——然后定理从里面长出来。

**每一步都不是发现，是决定**。

这就是「数学是创造」的具体内容：不是发明了结论，是**选定了边界，然后结论从边界里长出来**。

曼宁说阿罗「自由地选定一组符合民主的公理」。这句话说得对，也是他全篇最准的一句。

但他只数了第二次。第一次和第三次，他没数。

而这两次，恰恰最容易被当成「问题本来就该这样」——没人会问「为什么公平要表示成一个函数」，也没人会问「为什么独裁要算失败」。

**当你觉得一件事本来就该这样，往往是因为有人替你选过了**。

---

## 六、换掉任何一次，定理就变一个样

三次选择都是自由的，证据是：**换掉任何一次，结论都不一样**。

| 换哪次 | 换成什么 | 得到什么 |
| :-- | :-- | :-- |
| 第一次 | 允许基数效用（0–10 分打分） | Gibbard（1973）/ Satterthwaite（1975）：任何非独裁的确定性机制都可被策略操纵 |
| 第二次 | 要求偏好单峰 | Black（1948）中位选民定理：多数决可行，中位偏好即社会结果 |
| 第三次 | 允许独裁 | 定理失去信息量——「要么独裁要么不可能」变成「独裁可以」 |

第二条我们验过：单峰偏好下 64 个剖面，多数决违反传递性 0 次。

这说明什么？

**「无限制域」一旦放开，不可能性立刻消失**。所以上期说的「漏掉的那两条」，第一条的答案是：它不是清单上的第五项，它是定理能不能成立的总开关。

第二条——非独裁——的答案在第四节：它不是「隔离带」，它是「唯一幸存者的名字」。把它划掉，定理就空了。

**两条都不是普通公理。一条是门，一条是墙**。

## 七、三个小自测

**1. 把「至少 3 个选项」改成「至少 4 个」，定理还成立吗？**

成立。3 是最小的失效点，往上是 4、5、更多，全部失效——因为证明只需要 3 个选项就能构造反例，多出来的选项不增加难度。

**2. 单峰偏好让多数决可行，那「单峰」是不是一个更公平的假设？**

不是。它是对选民偏好的**限制**——现实里并不总成立（比如两个极端议题叠在一起时，偏好可能是双峰的）。Black 的结论说明的是：想让多数决可行，就得限制自由。可行性和自由，在这里是交换关系。

**3. 独裁是唯一满足五条的规则。那「非独裁」能不能改成「非寡头」？**

能，但代价是放弃中立性——中立性是说「同一套成对规则适用于所有选项对」。放弃它之后，寡头制（一个固定的小集团一致同意）是可行的。这正好说明第三次选择也可以换：换了之后定理换个样子，但仍然是定理。

---

## 最后一句

阿罗定理常被引用成「完美民主不存在」，然后配一句叹息。

但读到这里应该能看出来：**那个「不存在」是三处划界的必然结果**。

划界可以重划。换掉问题形状，换掉公理清单，换掉失败标志——每换一处，定理就变一个样。

**定理的力量不在结论，在选择。知道它能换，才知道它是被造的**。

下期换一个方向：不再看定理怎么造，看数学怎么谈论自己——范畴论，一门不说「对象是什么」、只说「对象怎么连」的语言。

---

> **本期的一句话总结**：一个不可能性定理 = 一个足够宽的对象类 + 一组足够强的公理 + 一个必须被排除的平凡解。独裁不是被民主赶走的，它是唯一没被赶走的。
